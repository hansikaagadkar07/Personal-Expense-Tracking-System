# Pennywise – Personal Expense Tracking and Analysis System

## About
Pennywise is a web-based application that helps users record,
manage, and analyze their personal expenses.

## Features
- User registration and login
- Add, edit, and delete expenses
- Track income and budgets
- View expense reports and charts
- Export expense data

## Technologies Used
- Python
- Flask
- MySQL
- HTML, CSS, JavaScript
- Pandas, NumPy, Matplotlib

## How to Run
1. Clone the repository.
2. Install the required packages using:
   pip install -r requirements.txt
3. Configure the database settings in your local `.env` file.
4. Run:
   python app.py
5. Open https://javeed.onrender.com in your browser.
